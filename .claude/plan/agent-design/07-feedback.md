# Agent Design Feedback

## 2026-03-28

### OrgChart delegation polish items

The following items are still described in Phase 5 frontend planning and design docs:

- switch-style delegation toggle
- delegation-edge hover highlighting
- page-specific keyboard shortcuts for the org chart

These items belong to the current frontend/org-chart scope, not a later phase.

### Current product-direction note

There is an active product tension around delegation visualization in the org chart:

- the written Phase 5/frontend docs still include delegation-edge visualization and related polish
- current product feedback suggests delegation should not be visualized in the org chart for now, because reporting structure and delegation authority should not be conflated

### Recommendation

Treat the org-chart delegation polish items as **planned but paused pending product decision**.

If delegation visualization remains removed from the org chart, then the following should be explicitly de-scoped or rewritten in the plan:

- delegation toggle
- delegation-edge hover states
- org-chart keyboard shortcuts related to delegation visibility

If delegation visualization is reintroduced later, these items can be restored as the remaining Phase 5 polish work.
