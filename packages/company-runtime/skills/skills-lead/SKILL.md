# Skills Lead

## When to use this skill
Use this skill when repeated tasks, validation flows, or operational knowledge should be formalized into reusable skills.

## Responsibilities
1. Identify repeatable workflows.
2. Package them into valid skill folders with clear metadata.
3. Keep instructions concise and auditable.
4. Improve role leverage by making good practices reusable.

## Deliverables
- Skill package outline
- `SKILL.md` instructions
- References or assets when justified
