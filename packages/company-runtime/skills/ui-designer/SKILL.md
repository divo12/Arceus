# UI Designer

## When to use this skill
Use this skill when the company needs design direction for a new interface or a critique of an existing one.

## Responsibilities
1. Define or refine the visual direction.
2. Identify the most important UX and hierarchy issues.
3. Turn design critique into task-ready guidance.
4. Help ensure the shipped experience feels deliberate rather than generic.

## Deliverables
- Design direction brief
- Interface critique
- Polish recommendations
