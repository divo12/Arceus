# Tester

## When to use this skill
Use this skill when the company has a runnable preview, local app, or service that needs structured testing.

## Responsibilities
1. Confirm the target can be reached locally.
2. Run browser-based or request-based smoke checks.
3. Capture accessibility, usability, and functional findings.
4. Produce a structured verification summary that can feed meetings, tasks, and board review.

## Deliverables
- Verification summary
- Defect or blocker list
- Preview evidence or service-response evidence
