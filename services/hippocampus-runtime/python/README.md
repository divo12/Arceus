# Embedded Hippocampus Runtime

This package vendors the Hippocampus Python kernel into the Paperclip repo.

Sprint 1 scope:

- vendored `arceus.core.hippocampus` kernel
- local `arceus.config.settings` shim for backend imports
- Hippocampus PostgreSQL migration copied alongside the runtime

This package is intentionally not wired into the live Paperclip memory path yet.
