Core Concept

5 Memory Tiers — Like a Human Brain

Working

Active task context. Held in cache. Cleared when task ends. 2hr TTL.

Static

Permanent facts. "React uses JSX." Never expires. Highest priority.

Dynamic

Episodic knowledge. Time-decays. Can be promoted to Static.

Procedural

Habits & rules. "When deploying, always run tests first."

Priming

Emotional state. Confidence, caution, morale. Shapes behavior.

Memories flow upward: Dynamic knowledge that proves reliable gets promoted to Static — just like how humans turn repeated experiences into long-term knowledge.

Data Isolation

Container-Based Memory Scoping

Every memory is tagged with a container that controls who can see it

Startup Shared

startup:{id}

Decisions visible to all employees in the startup. "We use React."

Employee Private

startup:{id}:emp:{agent}

Personal learnings only this agent can access. "I prefer TypeScript."

Task Scoped

startup:{id}:task:{task}

Temporary context for a specific task. Cleaned up on completion.
